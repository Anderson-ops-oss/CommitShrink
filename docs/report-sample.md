## 附录 A ｜ 由样张反推的数据契约

| 报告版块 | 所需字段 |
|---|---|
| 头部信息 | `author_name` `author_email` `period` `commit_count` |
| 量化指标 | `ts`（含时区）→ 派生 `weekday` `hour`；`message` → 派生 `vader_score`；常模百分位 ← `norm` 分布参数（symptoms.yaml） |
| 发作记录 | `hash`（短）`ts` `message` `file_paths[]`；派生：相邻提交间隔、文件重叠主题聚类 |
| 心电图 | `ts` + `vader_score` 按时间排序 |
| 处方依据 | `is_revert`（message 前缀 Revert / 全文 "This reverts commit" 回链解析）、深夜提交清单 |
| 暴发性提交检测 | `files_changed` `insertions` `deletions` `parents`（排除 merge） |

**collector 一次性抓取**：`hash, author_name, author_email, ts(unix+tz), message(full), parents` + `--numstat` 的 `file_paths[]`（每文件路径，原生输出）与 `files_changed / insertions / deletions` 聚合值。一条 `git log --pretty=format:... --numstat` 全部拿到，零依赖。

**抓取范围**：评估周期前后各扩 3 天（GIT-36.6 需回看 72 小时静默期、GIT-13.0 需前看 24 小时修复跟随），报告统计仍只计周期内提交。

**可选增强（仅本地仓库）**：reflog 检测 force-push / amend（供 GIT-88.8 使用）。数据缺失时该病症降级为："未检出（受检者拒绝提供该项样本）。"
